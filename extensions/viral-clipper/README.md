# Viral Clipper Plugin

Autopilot viral clipper Agent Plugin bundle for OpenClaw.

## Features
- **Caption-to-Short Route**: Synthesizes narration scripts, generates vertical 9:16 H.264/AAC videos with burned-in ASS captions, and packages post copy for Instagram Reels, YouTube Shorts, and TikTok.
- **Long-Video Clipping Route**: Analyzes SRT captions or Whisper transcript evidence, isolates highlight clips, reframes to 9:16 mobile aspect ratio, burns time-aligned subtitles, and retains source audio.
- **Deterministic & Local**: Pure Node + FFmpeg helper integration without external secret dependencies or automatic public posting.
